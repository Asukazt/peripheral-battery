# 0.1.1 预览版

本次更新调整应用与托盘图标，设备兼容范围和读取逻辑沿用 0.1.0。

- 应用图标改为深色底、浅色电池轮廓与绿色电量格。
- Windows 通知区域使用独立的透明背景电池图标，提高小尺寸辨识度。
- 两套 ICO 均包含 16、20、24、32、40、48、64、128、256px 九种尺寸。
- 更新应用内版本、日志与诊断包中的版本标识，便于定位问题。
- 同步公开源码、第三方素材说明、运行 ZIP 与 SHA-256 校验文件。

升级：退出旧版后，将运行包完整解压覆盖到原目录；保留原有 `data/`、
`logs/` 和 `diagnostics/`。程序仍使用 `PeriDock.exe` 启动。

验证：20 项协议与设置测试、36 张 UI 渲染、自包含发布构建及图标解码检查。
未完成干净 Windows 系统与完整连接方式/休眠重连测试。

运行包仍为 .NET 8.0.33；此前官方元数据记录的支持结束日为 2026-11-10。
本次没有迁移运行时或增加代码签名，继续作为 Pre-release 发布。
具体设备和系统限制见 README。

# 0.1.0 预览版

- 键盘、鼠标、耳机电量与实际连接方式集中显示。
- 通知区域图标、极简悬浮条、单击基本信息、双击详情。
- 读取毒蝰 V3 Pro 的 DPI。
- 记住悬浮条显示状态，可选择当前用户开机启动。
- 本地轮换日志、崩溃记录与主动导出脱敏诊断包。
- 修正黑鲨 V3 Pro 有线模式被无线链路离线应答误判为整机离线的问题。
- 鼠标与耳机同时有线连接已实测读取成功。
- 公开发行采用通用设备图标，不附厂商产品照片及私人设计图。

当前仅针对 README 所列设备，其他系统、固件、休眠重连和反复切换未全面验证。
该版使用 .NET 8.0.33；其支持结束日期为 2026-11-10，
后续长期维护需迁移运行时。建议在 GitHub 标记为 Pre-release。
