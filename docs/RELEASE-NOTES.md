# 0.2.0-preview.4 默认管理员启动与自定义图片

- 程序清单改为 `requireAdministrator`，双击 EXE 即请求管理员权限；确认一次后，设备查询子进程继承权限，刷新无需反复重启。
- 首次启动取消 UAC 时不启动；普通账户需管理员凭据。管理员仍被拒绝时提示检查驱动或设备接口，不提示反复提权。
- 图片与颜色窗口增加“导入自定义图片…”入口，支持 PNG、JPG、BMP、ICO，最大 10 MB，验证后转为本地 PNG。
- 导入后立即选中并保存，重启后恢复；重复导入可替换，取消或失败保留已有选择。原有私人图片保留，所选文件不上传。
- 同型号共用外观选择，延续官网取图、可选配色、缓存和按类别显示的托盘提示。

52 项离线回归及 78 张 UI 渲染检查通过，涵盖权限失败、USB / 2.4G / 蓝牙原有行为和自定义图片导入。
最终构建的管理员启动、实机读取、安装与压缩包校验结果见本版 VERIFY 记录。
管理员权限不保证解决未适配协议或所有驱动问题；不宣称全型号通杀。
运行包仍为未签名的 .NET 8.0.33 自包含 Pre-release；兼容限制见 README。

# 0.2.0-preview.2 USB 权限识别修复

- HID 元数据或读取接口被 Windows 拒绝访问时，继续保留设备身份、VID/PID 与已知 USB / 2.4G 通道。
- 区分“未连接”“访问被拒绝”“协议未适配”，通过隔离查询结果传递原生错误码。
- 权限失败后清空可展示的旧电量、充电与 DPI；发现失败也会使上一轮读数过期。
- 日志记录 VID/PID、Windows 错误码与原因，继续过滤设备路径、用户名路径和蓝牙地址。
- 托盘 / 详情设置菜单增加用户主动选择的“以管理员权限重启…”；默认仍是普通权限，取消 UAC 保留当前实例。
- 按安装目录区分预览版进程锁，独立目录的新包不会向另一安装目录写入控制信号。
- 保留旧键盘探测入口的蓝牙回退，以及已接入 USB、2.4G 和蓝牙协议的行为。

本轮普通权限实机：Viper V3 Pro USB (`1532:00c0 / MI_00`) 正确报告访问被拒绝（错误 5），
不显示旧电量；BlackShark V3 Pro 2.4G 读取 51%；Azoth X 蓝牙 GATT 读取 81%。
此前管理员诊断能够读到 Viper USB 电量、充电和 1600 DPI，但不是本次新版提权实测。
错误 5 不能证明是雷蛇软件占用；管理员权限也不保证解决所有驱动或未适配协议问题。

新增权限与提权取消回归，并扩展 100% / 150% / 200% UI 检查。
默认 `asInvoker`，未更改启动注册；本轮未实际确认 UAC、未验证全部型号、固件或干净系统。
保持 .NET 8.0.33 自包含、未签名的 Pre-release；兼容范围未扩大，不宣称全型号通杀。
完整解压新版到独立目录；不覆盖正在运行的私人组件。详细限制见 README 与发布验证记录。

# 0.2.0-preview.1 兼容测试版

- 自动发现 ROG / Razer HID 与已连接的品牌蓝牙设备，动态生成多设备列表。
- 增加多组雷蛇鼠标、无线键盘、部分耳机和 ROG 键鼠耳机的协议适配。

- 独立进程锁、设置与日志目录；测试版不注册开机启动。
