# 0.1.0 预览版

- 键盘、鼠标、耳机电量与实际连接方式集中显示。
- 通知区域图标、极简悬浮条、单击基本信息、双击详情。
- 读取毒蝰 V3 Pro 的 DPI。
- 记住悬浮条显示状态，可选择当前用户开机启动。
- 本地轮换日志、崩溃记录与主动导出脱敏诊断包。
- 修正黑鲨 V3 Pro 有线模式被无线链路离线应答误判为整机离线的问题。
- 鼠标与耳机同时有线连接已实测读取成功。
- 公开发行采用通用设备图标，不附厂商产品照片及私人设计图。

当前仅针对 README 所列设备，其他系统、固件、休眠重连和反复切换未全面验证。
该版使用 .NET 8.0.33；其支持结束日期为 2026-11-10，
后续长期维护需迁移运行时。建议在 GitHub 标记为 Pre-release。
